# icon-format-guide

게임 · 언리얼 · TA를 위한 **실전 가이드 허브**입니다.  
한국어 기준이며, 한/영 토글은 추후 지원 예정입니다.

## Preview

- **가이드 허브 (GitHub Pages):** https://ageia.github.io/icon-format-guide/
- **아이콘 포맷 단독 페이지:** https://ageia.github.io/icon-format-guide/format-guide.html
- **저장소:** https://github.com/Ageia/icon-format-guide

허브에서 탭(또는 URL 해시)으로 가이드를 고를 수 있습니다.

| 해시 | 가이드 | 상태 |
|------|--------|------|
| `#icon` | 아이콘 파일 포맷 | 완성 |
| `#texture` | 텍스처 포맷 | 예정 |
| `#material` | 머티리얼 블렌드 모드 | 예정 |
| `#nanite` | Nanite vs 일반 메시 | 예정 |
| `#import` | 텍스처 임포트 세팅 | 예정 |
| `#lighting` | Lumen vs 베이크 | 예정 |
| `#vfx` | VFX 텍스처·파티클 | 예정 |
| `#collision` | 충돌 메시 | 예정 |

예: https://ageia.github.io/icon-format-guide/#texture

## Contents

- `index.html` — 허브 (사이드바 탭 + 가이드 패널)
- `format-guide.html` — 아이콘 포맷 완성 가이드
- `badge_cloud.*` / `badge_star.*` — 멀티 포맷 아이콘 샘플
